This deployment is the terminal shell. The market engine — websocket ingestion, the three-model ensemble, the genetic evolution loop and the paper broker — must run as a persistent process, because it holds open streams and writes state continuously.

enter the base URL of your engine
START AN ENGINE ANYWHERE WITH DOCKER
docker run -p 8000:8000 -v omni:/app/data ghcr.io/you/omniscience
OR FROM SOURCE
pip install -r requirements.txt && bash run.sh
The engine exposes /api/health, /api/snapshot and /ws with permissive CORS, so any origin can link to it. Use HTTPS for the engine and this page will upgrade the socket to wss automatically.
